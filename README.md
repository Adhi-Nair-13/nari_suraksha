## 📱 About

Nari Suraksha is a women safety mobile application built using Flutter.

The objective of this application is to help women feel safer by providing instant emergency assistance, live location sharing, emergency contacts, SOS alerts, and intelligent safety tools.

The application follows a clean architecture with reusable widgets and a premium Material 3 design.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Adhi-Nair-13/nari_suraksha.git
```

Go inside project

```bash
cd nari_suraksha
```

Install packages

```bash
flutter pub get
```

Run

```bash
flutter run
```
